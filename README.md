# 🚗 یدک‌پارت — فروشگاه آنلاین قطعات یدکی خودرو

فروشگاه اینترنتی کامل قطعات یدکی خودروهای ایرانی و خارجی با تجربه کاربری
الهام‌گرفته از فروشگاه‌های مرجع این حوزه (نظیر yadakijat.com) اما با کد،
طراحی و محتوای کاملاً مستقل.

## 🛠 تکنولوژی‌ها

| بخش | تکنولوژی |
|-----|----------|
| فرانت‌اند | **Next.js 16** (App Router, Turbopack) + React 19 + TypeScript |
| بک‌اند | **Express 5** + TypeScript (ESM) |
| دیتابیس | **PostgreSQL** + **Drizzle ORM** |
| احراز هویت | **JWT** + bcryptjs |
| اعتبارسنجی | **Zod** (هر دو سمت) |
| استایل | CSS Modules + توکن‌های طراحی (بدون فریمورک CSS) |
| زبان رابط | فارسی، راست‌چین (RTL)، فونت وزیرمتن |

## 📁 ساختار پروژه

```
├── backend/
│   ├── src/
│   │   ├── db/schema.ts          # ۱۶ جدول Drizzle
│   │   ├── routes/               # ۱۵ فایل مسیر REST
│   │   ├── middleware/auth.ts    # verifyToken + requireRole
│   │   ├── lib/                  # اعتبارسنجی/استان‌ها/کوپن/نرخ‌محدود
│   │   └── scripts/seed.ts       # داده نمونه غنی
│   └── public/images/            # تصاویر SVG اختصاصی
└── frontend/
    └── src/
        ├── app/                  # ۳۰ مسیر (عمومی + پنل + ادمین)
        ├── components/           # هدر مگامنو، کارت محصول، ... 
        ├── context/              # AuthContext + CartContext
        └── lib/                  # api client، فرمت‌ها، تایپ‌ها
```

## 🚀 اجرای پروژه

### پیش‌نیازها
- Node.js ≥ 20 و PostgreSQL در حال اجرا
- (یا `docker compose up -d` برای دیتابیس)

### بک‌اند (پورت ۴۰۰۰)

```bash
cd backend
cp .env.example .env        # مقادیر را تنظیم کنید
npm install
npm run db:push             # ساخت جداول
npm run seed                # داده نمونه + ادمین پیش‌فرض
npm run dev                 # حالت توسعه (tsx watch)
```

### فرانت‌اند (پورت ۳۰۰۰)

```bash
cd frontend
cp .env.local.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:4000
npm install
npm run dev
```

## 🧩 امکانات کلیدی

### فروشگاه (عمومی)
- صفحه اصلی: اسلایدر بنر، دسته‌بندی‌ها، محصولات ویژه، مقالات
- کاتالوگ با فیلتر همگام با URL: دسته (با زیردسته)، برند، مدل خودرو،
  بازه قیمت، فقط موجود، فقط تخفیف‌دار + مرتب‌سازی + صفحه‌بندی
- جست‌وجو در نام و کد فنی قطعه
- صفحه محصول سروری (SSR) با گالری، مشخصات، جدول خودروهای سازگار،
  نظرات و امتیاز، محصولات مرتبط
- سبد خرید ماندگار (localStorage) + کد تخفیف + هزینه ارسال پویا
- تسویه چندمرحله‌ای: آدرس ذخیره‌شده یا جدید، کارت‌به‌کارت/پرداخت در محل
- پیگیری سفارش عمومی با «شماره سفارش + موبایل»
- مجله فنی، درباره ما، تماس با ما (فرم با نرخ‌محدود)

### پنل کاربر
- پروفایل (نام/نام‌خانوادگی/ایمیل/موبایل) + تغییر رمز
- دفتر آدرس با انتخاب آبشاری استان → شهر (فقط شهرهای همان استان)
- سفارش‌های من با جزئیات کامل و امکان لغو (در مراحل اولیه)
- علاقه‌مندی‌ها

### پنل مدیریت
- داشبورد آماری (فروش، سفارش‌ها، هشدار موجودی، نظرات در انتظار)
- سفارش‌ها: تغییر وضعیت، تأیید پرداخت، کد رهگیری پستی
- قطعات: CRUD کامل با تصاویر چندتایی و جدول سازگاری
- دسته‌بندی‌ها (درختی)، برندها و مدل‌های خودرو
- کدهای تخفیف (درصدی/مبلغی با سقف مصرف و انقضا)
- مدیریت نظرات (تأیید/رد)، بنرها، مقالات، پیام‌ها و کاربران

### امنیت
- رمزنگاری bcrypt، توکن JWT با انقضا
- کنترل دسترسی نقش‌محور روی همه مسیرهای مدیریتی
- اعتبارسنجی Zod روی همه ورودی‌ها (موبایل ۰۹xxxxxxxxx، کدپستی ۱۰ رقم،
  شهر∈استان، ...)
- نرخ‌محدود روی ورود/ثبت‌نام/تماس
- قیمت‌ها و تخفیف‌ها **فقط سرورمحور** محاسبه می‌شوند (قابل دستکاری نیستند)
- ثبت سفارش تراکنشی با قفل ردیف (`FOR UPDATE`) و کسر/بازگردانی موجودی

## 🔍 SEO
- متادیتای اختصاصی هر محصول (قابل تنظیم از پنل)
- JSON-LD: Product، BreadcrumbList، Article
- `sitemap.xml` پویا (محصولات + مقالات) و `robots.txt`
- URL های فارسی‌پسند اسلاگ‌دار

## 📋 قواعد داده ایرانی
- موبایل: `^09\d{9}$` — کدپستی: دقیقاً ۱۰ رقم
- استان‌ها: ۳۱ استان رسمی؛ شهر فقط از فهرست همان استان
- قیمت/تاریخ/عدد: قالب فارسی (`fa-IR`) در کل رابط

## ⚠️ نکات تولید (Production)
- `JWT_SECRET` قوی و یکتا تنظیم کنید
- توکن فعلاً در localStorage است؛ برای تولید جدی‌تر، مهاجرت به
  httpOnly cookie توصیه می‌شود
- فایل‌های `env.` را هرگز کامیت نکنید
- درگاه پرداخت آنلاین متصل نیست؛ روش‌های کارت‌به‌کارت/در محل پیاده شده‌اند
  (اتصال درگاه نیازمند کلید پرداخت است و می‌تواند در آینده اضافه شود)
