# 🔧 فروشگاه قطعات یدکی تویوتا

یک وب‌سایت فروش قطعات یدکی خودروهای تویوتا با معماری دو بخشی (فرانت‌اند و بک‌اند جداگانه).

## 🛠 تکنولوژی‌های استفاده‌شده

| بخش | تکنولوژی |
|-----|----------|
| فرانت‌اند | **Next.js 16** (App Router) + TypeScript |
| بک‌اند | **Express** + TypeScript |
| دیتابیس | **PostgreSQL** (با Docker) |
| ORM | **Drizzle ORM** |
| احراز هویت | **JWT** + bcrypt |
| استایل | CSS معمولی + CSS Modules |
| زبان رابط | فارسی (راست‌چین RTL) با فونت وزیرمتن |

## 🚀 راه‌اندازی و اجرا

### پیش‌نیازها
- نصب بودن **Node.js** نسخه ۲۰ به بالا
- نصب بودن **Docker** و **Docker Compose**

### قدم‌به‌قدم

**۱) اجرای دیتابیس (PostgreSQL)**
```bash
docker compose up -d
```
این دستور PostgreSQL را روی پورت ۵۴۳۲ و یک رابط وب (Adminer) را روی پورت ۸۰۸۰ اجرا می‌کند.

**۲) راه‌اندازی بک‌اند**
```bash
cd backend
npm install              # نصب وابستگی‌ها
npm run db:push          # ساخت جداول در دیتابیس
npm run seed             # ثبت داده‌های اولیه (ادمین + قطعات نمونه)
npm run dev              # اجرای سرور روی http://localhost:4000
```

**۳) راه‌اندازی فرانت‌اند** (در یک ترمینال جدا)
```bash
cd frontend
npm install
npm run dev              # اجرای سایت روی http://localhost:3000
```

حالا می‌توانید سایت را در مرورگر در آدرس **http://localhost:3000** ببینید.

## 🔑 ورود به‌عنوان مدیر

پس از اجرای `npm run seed`، یک کاربر ادمین پیش‌فرض ساخته می‌شود:

| فیلد | مقدار |
|------|-------|
| ایمیل | `admin@parts.ir` |
| رمز عبور | `admin123` |

با این حساب می‌توانید وارد **پنل ادمین** شوید و قطعات، دسته‌بندی‌ها و سفارش‌ها را مدیریت کنید.

## 🗺 راهنمای صفحات

| آدرس | توضیح |
|------|-------|

| `/admin` | داشبورد ادمین |
| `/admin/parts` | مدیریت قطعات (افزودن/ویرایش/حذف) |
| `/admin/categories` | مدیریت دسته‌بندی‌ها |
| `/admin/orders` | مدیریت سفارش‌ها (تغییر وضعیت) |

## 📜 دستورهای مفید (در پوشه `backend/`)

| دستور | کاربرد |
|-------|--------|
| `npm run dev` | اجرای سرور در حالت توسعه (با reload خودکار) |
| `npm run db:push` | اعمال تغییرات schema روی دیتابیس |
| `npm run db:studio` | باز کردن Drizzle Studio (رابط بصری جداول) |
| `npm run seed` | پر کردن دیتابیس با داده‌های اولیه |
| `npm run build` | ساخت نسخه نهایی (production) |

---

## 🔄 نحوه کار احراز هویت (به‌طور خلاصه)

1. کاربر در `/register` یا `/login` اطلاعات را وارد می‌کند.
2. بک‌اند پسورد را بررسی/هش می‌کند و یک **توکن JWT** می‌دهد.
3. فرانت‌اند توکن را در `localStorage` ذخیره می‌کند.
4. در هر درخواست بعدی، توکن به‌صورت خودکار در هدر `Authorization` ارسال می‌شود.
5. بک‌اند توکن را تأیید کرده و نقش کاربر (user/admin) را بررسی می‌کند.

> **نکته:** ذخیره توکن در `localStorage` برای یک پروژه آموزشی ساده و کافی است. برای محیط تولید بهتر است از کوکی `httpOnly` استفاده شود.

## 🧹 ریست کردن دیتابیس (در صورت نیاز)

اگر خواستید دیتابیس را کاملاً از نو بسازید:
```bash
docker compose down -v      # حذف دیتابیس فعلی
docker compose up -d        # ساخت دیتابیس جدید
cd backend
npm run db:push             # ساخت جداول
npm run seed                # داده‌های اولیه
```
